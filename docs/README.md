## 🎯 **Getting Started**

### Untuk Developer Baru

1. **Baca Architecture First**: Mulai dengan dokumentasi di folder [`architecture/`](./architecture/)
2. **Ikuti Development Guide**: Lanjut ke folder [`development/`](./development/) untuk panduan setup
3. **Check API Documentation**: Lihat folder [`api/`](./api/) untuk integrasi backend
4. **Review Current Tasks**: Check folder [`task/`](./task/) untuk task yang sedang berjalan

### Untuk Feature Development

1. **Use Architecture Template**: Gunakan [`Clean Architecture Template`](./architecture/clean_architecture_template.md)
2. **Follow API Guidelines**: Referensi [`API Endpoints Structure`](./api/01-API-Endpoints-Structure.md)
3. **Check Implementation Guides**: Lihat [`Implementation Guide`](./development/implementation_guide.md)

## 📝 **Contribution Guidelines**

### Menambah Dokumen Baru

1. **Pilih Kategori yang Tepat**: Architecture, API, Development, atau Task
2. **Gunakan Template Metadata**: Ikuti format metadata yang sudah ada
3. **Update README**: Tambahkan link ke dokumen baru di section yang sesuai
4. **Cross-Reference**: Tambahkan referensi silang ke dokumen terkait

### Memperbarui Dokumen

1. **Version Control**: Update versi dan tanggal di metadata
2. **Changelog**: Tambahkan ringkasan perubahan
3. **Review**: Mint review dari tim terkait
4. **Notify**: Beri tahu stakeholder tentang perubahan penting
